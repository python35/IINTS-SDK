# v1.0.0

Release date: 2026-03-09

## Overview

This is the first public production release of IINTS-AF SDK.

## Highlights

- Production release baseline for simulation, safety validation, and audit-ready reporting.
- CLI branding update: `iints --help` now shows official IINTS ASCII logo.
- Documentation hardening: quickstart/manual pages now explicitly require active virtual environments.
- MDMP integration finalized for public release:
  - optional dependency moved to published package (`mdmp-protocol>=0.2.1`)
  - MDMP sync gate works against public MDMP repository (no private token required)
  - Dependabot automation added to keep MDMP dependency updates flowing into SDK.

## Stability and Scope

- Research use only.
- Not a medical device.
- No clinical dosing advice.
