# SDK v1.5.37 and Research Workbench beta 0.2.14

## Automatic results preparation

- Unique output directories prevent runs from overwriting earlier experiments.
- Desktop runs can prepare full-file metrics, glucose plots, MDMP data checks and
  a reproducibility package in sequence. Local AI review is optional.
- Reopening an unchanged CSV restores the saved artifact links. SHA-256 checks
  prevent restoring stale preparation metadata for a changed file.
- Private signing keys remain outside shareable result folders.

## Desktop beta 0.2.14

- A recorded Physiology map replaces the decorative illustrated torso, with
  model-specific states, fluxes, units and signed flow directions.
- Correct Bergman EGP/uptake mapping and insulin-depot selection; no invented
  fallback values and no inference of stability from a single glucose value.
- History refreshes after folder changes. Technical metadata is collapsible.
- The user guide includes screenshots of a real synthetic test run.
- Version-tagged updater downloads prevent a changing stable channel from
  pairing old signatures with new binaries.

## Updating

Existing Tauri users: open **Settings**, check for an app update, and install it.
The app downloads the signed update and restarts; there is no need to manually
fetch a DMG or EXE. Save your work and let active jobs finish first. On Windows,
installer or permission prompts can still appear. On macOS, run the app from a
writable installed location, not directly from the mounted DMG.

Also use **Install or update Python SDK** in Settings to install SDK 1.5.37,
then refresh versions. App and engine updates are separate. The app does not
silently install external scientific tools or AI model weights.

The Mac download targets Apple Silicon; Linux targets x86-64 AppImage and Windows
x64. Legacy PySide installations do not migrate through the Tauri updater.
Updater signatures authenticate updates; they are not Apple notarization or
Windows Authenticode certificates. OS trust prompts may still appear.
