# v1.5.36

Release `v1.5.36` is a follow-up patch to `v1.5.35` that fixes three CI/release issues found immediately after `v1.5.35` published: a real (not just static) bug in a rarely-exercised patient model subclass, a Node.js compatibility break in the desktop app's test tooling, and a test-collection guard gap. No feature changes.

## Fixes

- Fixes `AdvancedMetabolicModel._ode()`, which was missing the optional `record` parameter its superclass (`BergmanPatientModel._ode()`) declares. This was not only a type-checker error: `flux_snapshot()` calls `_ode(..., record=...)`, which raised `TypeError` on any `AdvancedMetabolicModel` instance. It now accepts and ignores `record`, since this 18-state model does not publish a compartment schema of its own.
- Fixes the desktop app's headless compartment-view test harness for Node.js 21+, which ships a read-only `navigator` global; the harness now redefines the property instead of assigning to it.
- Adds a missing `torch` import guard to a statistics test, so a minimal install without the optional `research` extras collects the full test suite instead of aborting on one unconditional import.

## Compatibility

- Python: `3.10` through `3.14`.
- Desktop beta: `0.2.9`.
- No behavior change for any code path other than `AdvancedMetabolicModel.flux_snapshot()`, which previously raised and now returns an empty mapping.

IINTS-AF remains a research and educational system. This release does not provide clinical validation, regulatory certification, or treatment functionality.
