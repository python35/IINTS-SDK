# EUCYS jury folder — maintained sources

The folder a juror actually reads is a generated bundle of 91 files (about 29 MB) and is
not in this repository, in keeping with the rule in `.gitignore` that generated EUCYS
bundles stay out and their sources live under `docs/eucys`. What is here is everything
needed to rebuild it, plus the two documents that are written by hand rather than
computed.

## Rebuild

```bash
python docs/eucys/jury/scripts/compute_runs.py   # five simulations, seed 42, raw traces + metrics
python docs/eucys/jury/scripts/make_figures.py   # the four figures, computed from those traces
python docs/eucys/jury/scripts/curate.py         # assembles the folder and writes MANIFEST.csv
```

`compute_runs.py` and `make_figures.py` write into a `fresh/` working directory;
`curate.py` reads that plus files from the repository and copies the result to the
destination named at the top of the script. The runs are seeded, so the metrics and the
numbers printed on the figures reproduce exactly.

## What is in here

| Path | What it is |
| --- | --- |
| `00_START_HERE.md` | The reading route for a juror, with the results table. Written by hand. |
| `PROVENANCE_NOTES.md` | Where every class of evidence comes from, and the two defects this build exposed. Written by hand. |
| `MANIFEST.csv` | One row per file in the built folder: folder, file, provenance class, bytes, sha256, source, note. Generated by `curate.py`. |
| `figures/` | The four computed figures, kept here so the documents above are readable on GitHub. |
| `scripts/` | The three build scripts. |

Folder references inside `00_START_HERE.md` and `PROVENANCE_NOTES.md` (`06_RESULTS/`,
`02_PUMP_MECHANICS/` and so on) are relative to the *built* folder, not to this
directory. The same figures are in `figures/` here.

## The two findings

`PROVENANCE_NOTES.md` records both in full. In short: a determinism check was failing
because the safety report hashed the temporary directory a run wrote to rather than the
run's output — fixed in `src/iints/validation/replay.py` with a regression test for the
real case, not a stubbed one. And the pump figure labelled the algorithm's commanded
insulin as delivered insulin; `bolus_insulin_units` and `basal_insulin_units` are what
the algorithm asks for, `delivered_insulin_units` is what survives the safety supervisor
and the pump model, and the two differ on exactly the steps where `safety_triggered` is
set.
