# One-Liner Bank

## Ultra Short

IINTS is an open research SDK for testing insulin-algorithm ideas safely in simulation before anyone thinks about hardware.

## For Doctors

IINTS helps turn insulin-algorithm concepts into reproducible simulated studies with clear safety limits, source-backed metrics, and audit artifacts.

## For Engineers

IINTS is a Python SDK and CLI that packages virtual patients, scenarios, data import, validation, reporting, edge demos, and bench-only hardware workflows.

## For Jury Members

The project asks: can we make early diabetes-technology research more transparent, reproducible, and safer before real-world testing?

## For Hardware Viewers

The pump/PCB work is a bench demonstrator; the SDK’s role is to test algorithms in simulation and package safe fake commands, not dose real insulin.
