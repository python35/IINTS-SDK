# v1.2.0

Release date: 2026-03-21

## Overview

This release turns CareLink import support into a complete personal-data workflow inside IINTS-AF. Users can now import MiniMed / CareLink exports, generate a personal dashboard and poster, reuse the derived scenario for experiments, and ask the local Mistral assistant to explain the imported glucose patterns.

## Highlights

- Added `iints carelink-workbench` for one-command personal-data setup
- Added new CareLink APIs:
  - `build_carelink_workbench(...)`
  - `load_carelink_event_log(...)`
  - `import_carelink_timeline(...)`
- Added visual outputs for imported personal data:
  - `carelink_dashboard.png`
  - `carelink_dashboard.html`
  - `carelink_poster.png`
  - `carelink_metrics.json`
  - `carelink_timeline.csv`
- Added AI-ready payload generation for imported CareLink workspaces
- Updated the local AI prompt layer so explanations now also fit imported personal glucose datasets, not only simulation runs

## Example Flow

```bash
python -m pip install -U "iints-sdk-python35[mdmp]==1.2.0"
ollama pull ministral-3:3b
iints ai local-check --model ministral-3:3b

iints carelink-workbench \
  --input-csv "/path/to/CareLink export.csv" \
  --output-dir results/personal_carelink

iints ai report results/personal_carelink --model ministral-3:3b
iints ai trends results/personal_carelink --model ministral-3:3b
iints ai explain results/personal_carelink --model ministral-3:3b
```

## Why This Matters

With `v1.2.0`, the SDK no longer stops at “import your data.” It now gives users a real workflow:

- inspect imported pump/CGM history visually
- convert it into an experiment-ready scenario
- generate a poster for demos or review
- use a local open Mistral-family model to explain trends and anomalies

## Scope Notes

- Research use only
- Not a medical device
- No dosing advice
- AI output remains gated by MDMP verification
