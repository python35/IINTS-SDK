# Command Glossary

| Command | User meaning |
| --- | --- |
| `iints doctor` | check environment, install state, optional capability readiness |
| `iints demo` | fastest zero-config demonstration |
| `iints quickstart` | creates a local self-contained project |
| `iints run preview` | sanity-check a run before doing the full simulation |
| `iints run` | execute a simulation |
| `iints run-full` | run plus audit/report/baseline artifacts |
| `iints validate-run` | validate output metrics against a profile |
| `iints data list` | list dataset registry entries |
| `iints import-data` | standardize local CGM CSV data |
| `iints import-carelink` | import Medtronic/CareLink-style exports |
| `iints import-tidepool` | import Tidepool data when credentials/API are available |
| `iints run-eucys-study` | run the fixed EUCYS study matrix |
| `iints demo-live` | export/show/run a call-friendly demo |
| `iints edge pump` | bench-only Pico pump package/upload helpers |
| `iints jetson endurance` | long-running edge research workflow |
