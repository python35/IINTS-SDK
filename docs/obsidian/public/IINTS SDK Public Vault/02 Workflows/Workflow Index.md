# Workflow Index

> [!tip] Why this exists
> The SDK is powerful, so this page turns it into repeatable workflows. Pick the workflow, follow the gates, then save the evidence.

## Workflows

| Workflow | Use it when | Output |
| --- | --- | --- |
| [[Workflow - First Demo to Evidence Bundle]] | you need to show IINTS quickly | demo result + short explanation |
| [[Workflow - Build Test Validate Algorithm]] | you are creating an insulin algorithm | simulated run + validation bundle |
| [[Workflow - Import Data to Realism Check]] | you have CGM/pump data | standardized data + realism report |
| [[Workflow - Jetson Long Run]] | you run edge endurance experiments | long-run folder + monitor notes |
| [[Workflow - Pump Lab Bench Gate]] | you package code for Pico bench demo | dry-run package + safety gate checklist |

## Workflow Rule

Every workflow should leave behind four things:

- command used
- input files/configs
- output folder
- source or limitation note
