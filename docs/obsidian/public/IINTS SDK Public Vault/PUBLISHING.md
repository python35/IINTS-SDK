# Publishing This Vault

This folder is the public-safe vault. It is suitable for sharing as a ZIP or publishing with Obsidian Publish.

## Share As ZIP

Upload `IINTS_SDK_Public_Obsidian_Vault.zip` and tell users:

1. Download and unzip.
2. Open Obsidian.
3. Choose `Open folder as vault`.
4. Select `IINTS SDK Public Vault`.
5. Start at `00 START HERE.md`.

## Publish With Obsidian Publish

Obsidian Publish is a paid Obsidian service. To publish:

1. Open this public vault in Obsidian.
2. Go to Settings -> Publish.
3. Choose this vault, not the private/internal vault.
4. Publish all public notes and canvases.
5. Do not publish private notes, local results, credentials, or personal meeting notes.

## What Was Excluded

- private docs folders
- personal meeting/contact details
- heavy raw results
- private keys or secrets
- local model artifacts
- full source-code mirror
