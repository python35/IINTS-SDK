APPENDIX C

Jury answer index

The nine questions most likely to arrive first, with the shortest defensible answer and where to go for detail.

The opening nine

1 · Is this clinically validated?

No. It is a research and educational simulator, not a medical device, and no number it produces may determine a real insulin dose. Software correctness is tested extensively; physiological plausibility is supported with tools; experimental validation is partial; clinical validation is not claimed. → 0.1 → Ch 28

2 · Did you invent these equations?

No. Sixteen formulas are registered in the source with LaTeX, units, literature DOIs and an evidence class. Seven are adapted from published models, nine are marked heuristic — the code labels its own assumptions. → App B

3 · Why an ODE rather than machine learning?

Because insulin acts with memory over hours, and every term needs a unit and a source. An ODE expresses insulin-on-board as a physical state, so dose stacking emerges rather than being coded. ML exists here, but as a bounded predictor behind four gates. → Ch 2 → Ch 22

4 · Could an AI change a dose?

Only as a candidate capped at 1.0 U per step, and only through the same independent supervisor as every other controller. A language model has no numerical authority at all — the registry exports ai_numeric_authority: false. → Ch 1

5 · What happens if insulin sensitivity halves?

Measured on an identical scenario: mean glucose 145 → 206 mg/dL, TIR 80% → 33%, time above 180 rising from 20% to 68%. The effect is asymmetric because hepatic suppression is already saturated while peripheral disposal is not. → Ch 27

6 · How do you know a parameter is biologically realistic?

For the published ones — \(k_{12}\), \(k_e\), EGP₀, \(V_G\), the action-channel constants — from the source paper, with the unit conversion recorded. For the IINTS scalars, I do not: they are declared assumptions, default to inert, and the registry states they require calibration before quantitative interpretation. → App A

7 · How does PD-L1 or the immune system enter the model?

It does not. There is no immune-cell model, no beta-cell mass dynamics and no PD-L1 term in any equation; the only occurrence is a label in a static reference protein panel. The graft extension is a single exponential decay on an abstract survival fraction, off by default. → Ch 17

8 · What is the weakest part of the work?

Parameter identifiability — a nineteen-state model has more parameters than the available inputs can identify — and, in the results, the 6.45% mean time below 70 mg/dL in the clean benchmark arm, which is above the 4% consensus target and is the principal open finding. → Ch 28 → Ch 26

9 · What would make it credible enough to use?

Parameter identification against clamp or well-characterised CGM data; external validation by replaying real patient days and reporting the error; and cross-validation against a certified simulator on a shared protocol. None is done, and more simulation does not substitute for any of them. → Ch 28

!

If you take one habit into the room: when a question could be about mathematics, physiology, experiment or clinic, say which one you are answering before you answer it. Almost every difficult question in this field is difficult only because those four are being conflated.
