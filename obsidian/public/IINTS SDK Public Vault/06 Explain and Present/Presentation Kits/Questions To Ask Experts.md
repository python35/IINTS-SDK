# Questions To Ask Experts

## Doctors

- Which simulation assumptions would you distrust first?
- Which safety metric should be on page one of every report?
- Which wording sounds too medical-device-like?
- What would make this easier to review clinically?

## Engineers

- Which interface should be made more deterministic?
- Which artifact is missing for reproducibility?
- Where would you add tests before release?
- Which part should be separated into a plugin/module?

## AI Researchers

- Which validation split would convince you more?
- How should uncertainty be reported?
- Which subgroup checks matter most?
- What would make local AI assistance safer?

## Hardware People

- Which failure mode is most dangerous in the bench setup?
- Which interlock should be hardware-enforced instead of software-enforced?
- What should the Pico refuse by default?
