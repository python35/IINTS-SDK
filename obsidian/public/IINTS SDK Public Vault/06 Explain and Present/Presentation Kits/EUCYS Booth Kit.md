# EUCYS Booth Kit

## 30-Second Pitch

IINTS is an open research SDK for testing insulin-algorithm ideas safely in simulation. It combines virtual patients, real-data import, physiological sanity checks, reports, edge demos, and a strict bench-only hardware boundary.

## 3-Minute Flow

1. Problem: insulin algorithms are hard to test transparently and safely.
2. Method: simulate first, validate outputs, record sources/configs.
3. Demo: run one command and show a result bundle.
4. Evidence: open [[Source Library Index]] and [[Claim Library]].
5. Future: improve data realism, edge research, and safe bench hardware.

## Strong Closing

The value is not that IINTS replaces clinical research. The value is that it makes the earliest research steps more transparent, reproducible, and safer to discuss.
