# Presentation Kit Index

> [!tip] Use this before every call, booth, demo, or jury moment
> Pick the audience first. Then use the right story, right demo, and right safety boundary.

| Audience | Open | Main objective |
| --- | --- | --- |
| doctors | [[Doctor Call Kit]] | show clinical awareness without overclaiming |
| engineers | [[Engineer Deep Dive Kit]] | show architecture, tests, reproducibility |
| EUCYS jury | [[EUCYS Booth Kit]] | explain novelty, method, impact, limitations |
| quick demo | [[5-Minute Live Demo Script]] | run a smooth live walkthrough |
| expert feedback | [[Questions To Ask Experts]] | get useful critique instead of vague praise |
| printed material | [[Print Pack Checklist]] | prepare PDFs/tables/posters |

## Golden Rule

Every presentation should include three layers:

- what the SDK does
- what evidence backs it
- what it explicitly does **not** claim
