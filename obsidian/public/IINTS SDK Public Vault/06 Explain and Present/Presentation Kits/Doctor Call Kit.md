# Doctor Call Kit

## Opening

IINTS is not a treatment system. It is a pre-clinical research SDK that helps test insulin-algorithm ideas in simulation, with source-backed metrics and strict safety boundaries.

## What To Show

1. [[SDK User Home]] for the user flow.
2. [[Physiology and Safety Sources]] for metric grounding.
3. [[Realism Reference Envelopes]] for plausibility checks.
4. One generated report or demo bundle.
5. [[Safety Boundary Script]] before hardware discussion.

## Doctor Questions To Invite

- Which physiological assumptions look too simplified?
- Which safety metrics would you expect in a pre-clinical report?
- Which wording sounds too close to medical-device claims?
- Which patient subgroups should be evaluated separately?

## Avoid

- live hardware-first demos
- saying AI doses insulin
- implying simulator success equals patient safety
