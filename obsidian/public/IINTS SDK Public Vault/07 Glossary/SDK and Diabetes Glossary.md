# SDK and Diabetes Glossary

| Term | Meaning for IINTS users |
| --- | --- |
| CGM | Continuous glucose monitoring; time-series glucose input used in imports/reports. |
| TIR | Time in range, usually 70-180 mg/dL in SDK reports. |
| TBR | Time below range; hypoglycemia burden. |
| TAR | Time above range; hyperglycemia burden. |
| ISF | Insulin sensitivity factor, mg/dL change per unit insulin in profile assumptions. |
| ICR | Insulin-to-carb ratio, grams of carbohydrate covered by one unit in profile assumptions. |
| Basal | background insulin assumption/rate in virtual patient or algorithm context. |
| Bolus | insulin dose event, often meal/correction related in simulation. |
| Virtual patient | simulated patient model used for pre-clinical testing. |
| Scenario | scripted meals, exercise, stress, sensor events, or study conditions. |
| Realism check | plausibility comparison against empirical envelopes, not clinical validation. |
| MDMP | data quality/certification layer for medical-data style reproducibility. |
| Evidence bundle | output folder containing results, metadata, source notes, and report artifacts. |
| Bench-only | hardware workflow isolated from humans/animals/real insulin. |
