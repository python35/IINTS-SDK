## Safety Boundary

IINTS is a research and education SDK. It is not a medical device, not treatment advice, and not for real insulin dosing. Pump/Pico material in this vault is bench-only.

## How To Use

1. Open this folder as a vault in Obsidian.
2. Start with [[SDK User Home]].
3. Use backlinks/graph to move between sources, claims, commands, and hardware notes.
4. If publishing with Obsidian Publish, publish this public vault only, not the private/internal vault.
