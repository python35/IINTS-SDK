# User Journey - Local AI Research

> [!tip] Who this is for
> A local AI researcher who wants a clear path through the SDK without reading the whole repository first.

## Goal

Get from intention to a reproducible IINTS output bundle with the fewest confusing detours.

## Steps

- [ ] Keep local AI as an assistant for summaries, QA, and experiment planning.
- [ ] Use local models to inspect reports and logs, not to dose insulin.
- [ ] Document model, prompt, data, and hardware in every study bundle.
- [ ] Run deterministic replay and validation checks around AI-produced changes.
- [ ] Use source-backed language for claims.

## Commands

```bash
iints ai local-check --model ministral-3:8b
iints research prepare-dataset --help
iints replay-check --help
```
