# User Journey - EUCYS or Jury Demo

> [!tip] Who this is for
> A presenter who wants a clear path through the SDK without reading the whole repository first.

## Goal

Get from intention to a reproducible IINTS output bundle with the fewest confusing detours.

## Steps

- [ ] Explain the problem in plain language.
- [ ] Show one live command that creates real outputs.
- [ ] Open the report/poster/evidence table.
- [ ] Show the source library when asked why numbers mean something.
- [ ] End with the safety boundary and future work.

## Commands

```bash
iints demo-live --output-dir results/live_demo
open results/live_demo
```
