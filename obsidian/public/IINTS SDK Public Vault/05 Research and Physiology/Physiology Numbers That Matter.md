# Physiology Numbers That Matter

| Number | Meaning |
| --- | --- |
| `70-180 mg/dL` | Time in Range target |
| `<70 mg/dL` | low-glucose exposure |
| `<54 mg/dL` | clinically more serious low threshold |
| `>180 mg/dL` | high-glucose exposure |
| `5 min` | common CGM/simulation cadence |
| `24 h` | full day evaluation |
