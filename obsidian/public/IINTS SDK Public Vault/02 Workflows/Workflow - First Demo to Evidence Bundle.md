# Workflow - First Demo to Evidence Bundle

## Goal

Get from a clean install to something you can show in a call, booth, or school discussion.

## Steps

- [ ] Run `iints doctor`.
- [ ] Run `iints demo`.
- [ ] Run `iints demo-live --output-dir results/live_demo` when you want a presentable flow.
- [ ] Open the generated result folder.
- [ ] Explain the output with [[How To Use Sources In A Report]].
- [ ] If someone asks about evidence, open [[Sources by SDK Feature]].

## Command Block

```bash
iints doctor
iints demo
iints demo-live --output-dir results/live_demo
```

## Talk Track

IINTS lets a user move from an algorithm idea to a reproducible simulated result bundle. The demo is not treatment advice; it shows how simulation, validation, and source-backed reporting work together.

## Done Means

- [ ] Result folder exists.
- [ ] You can explain what was simulated.
- [ ] You can point to the source library.
- [ ] You can state the safety boundary clearly.
